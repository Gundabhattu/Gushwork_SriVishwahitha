# Mangalam HDPE Pipes & Coils - Premium Website

A responsive, feature-rich website for Mangalam, a premium HDPE pipes and coils manufacturer. Built with modern web technologies featuring interactive carousels, zoom previews, and complete product portfolio.

## 🎯 Features

- **Interactive Product Carousel** - 6-slide carousel with smooth transitions
- **Zoom Preview** - Click any image to see an enlarged preview
- **Responsive Design** - Works perfectly on desktop, tablet, and mobile
- **Sticky Header** - Navigation bar appears on scroll
- **Smooth Animations** - CSS transitions and hover effects
- **Accessibility** - ARIA labels, keyboard navigation support
- **Performance Optimized** - Lazy loading, debounced events

## 🚀 Quick Start

1. **Extract the project**
   ```bash

   cd gushwork
   ```

2. **Open in browser**

   - Or open with your preferred browser

3. **View online**
   - No server required - works with file:// protocol

## 🔧 Customization

### Add New Products
Edit `script.js` and add to `CAROUSEL_ITEMS`:
```javascript
{
    id: 7,
    title: 'Your Product Name',
    image: 'images/your-product.jpg'
}
```

### Change Colors
Edit CSS variables in `styles.css`:
```css
--primary-color: #1e3a8a;
--accent-color: #C0392B;
```
