## 💡 How to Use

### View the Website
1. Open `/Users/srivishwahitha.g/gushwork/index.html` in a browser
2. Watch the manufacturing animations
3. Click carousel buttons or dots to navigate
4. Scroll down to see more content

### Customize Configuration
Edit `script.js` CONFIG object:
```javascript
const CONFIG = {
  carousel: {
    autoPlay: true,        // Enable/disable auto-rotation
    autoPlayInterval: 5000, // Change rotation speed
    canvasWidth: 800,      // Adjust canvas size
    canvasHeight: 500,
  }
}
```

### Modify Colors
Edit CSS variables in `styles.css`:
```css
:root {
  --primary-blue: #0066cc;
  --accent-blue: #00a3ff;
  --light-bg: #f5f7fa;
  /* ... more variables ... */
}
```
